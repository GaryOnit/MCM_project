## 2. 清洗规则

| 规则 | 内容 |
| --- | --- |
| R1 编码 | 原附件按 GBK 读取；所有输出按 UTF-8-SIG 写，Excel 直接打开不乱码。 |
| R2 日期解析 | `2023/9/5`、`2023-09-05`、`2023年9月5日` 统一解析为 datetime，失败置 NaT 并计数（实测失败 0 条）。 |
| R3 去重 | 同一主键（日粒度=中心+日期；小时粒度=中心+日期+小时）多条记录取**算术平均**，保留 `记录条数` 列。取均值的理由：重复来源无法判断可信度，均值对随机重复无偏且抗单点误差；实测四份附件重复键均为 0，该规则仅作防御。 |
| R4 排序 | 按中心编号自然序（SC7 在 SC12 之前）+ 日期 + 小时升序，稳定排序（mergesort）。 |
| R5 小时网格补齐 | 按 中心×日期×0..23 构造完整网格左连接；缺格保留在 `货量_原始`（NaN），`货量` 记 0。依据见 §3.3：填 0 后小时合计与附件1 日货量的中位相对误差仅 0.11%，即缺格等价于该小时无货量。 |
| R6 异常值 | 按中心分别用 IQR(1.5) 与 3σ 双规则标记，输出 `异常_IQR`/`异常_3σ`/`异常标记`，**一律不删除**。大促脉冲是真实业务信号，剔除会破坏后续峰值建模。 |
| R7 突增突降 | 按中心计算 `环比倍数 = 当日货量 / 前一自然日货量`，>5 或 <1/5 记入跳变清单（见 §4.3）。 |
| R8 只读保护 | `附件/`、`结果/结果/` 下原始文件全程只读；提交模板已原样备份到 `模板备份/`（本会话沙箱禁写 `结果/`，故备份放在工作区根目录，内容与原始模板逐字节一致，SHA256 已核对）。 |
