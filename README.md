## 4 方法要点与关键结果

| 问题 | 方法 | 关键结果 |
|---|---|---|
| 1 日货量 | RTW-WMA（水平 × 星期因子，k=10）+ **周增长率漂移** (1+g)^{h/7} | 回测 WAPE 21.91%（常态日 12.43%），优于朴素均值/加权 MA/Holt-Winters/无漂移版 |
| 1 小时货量 | 固定小时占比（剔 7 个促销日）+ 最大余数法 | 小时 WAPE 20.06%；Σ小时 = 日货量 0 误差 |
| 2 线路修正 | 有向流量矩阵 + 开关线路重分配 + 全网守恒 + ±5% 截断 | f ∈ [0.9504, 1.0157]，18/57 个中心有结构变化 |
| 3 班次人数 | 允许积压 + 日末清零的 **Hall 条件**整数规划，正式工优先 | 116,925 人天（正式 53,543 + 临时 63,382），人效 21.89/25 |
| 4 逐人排班 | 轮转模式池 + 贪心派活，≤25 天、连续 ≤7 天 | 11,491 人天，出勤率 83.33%（完全均衡），连续最长 6 天 |

**六种排班口径对照**（论文第九章，同一需求曲线）：

| 口径 | 人天 | 倍数 | 可执行性 |
|---|---:|---:|---|
| 日总量工时下界 | 102,398 | 1.000 | 仅下界 |
| **允许积压 + 日末清零（Hall，提交版）** | **116,925** | **1.142** | 日末积压 0 |
| 到期累计（方向错误） | 115,751 | 1.130 | 日末仍积压 19,819 件 |
| 严格逐小时 | 213,611 | 2.086 | 人力被峰值钉死 |
| 8 小时周转 | 142,793 | 1.394 | +22.1%，独大班次搬家 |
| 单班 ≤40% | 184,545 | 1.802 | +57.8%，靠稀释总人数 |

## 5 数据与假设

全部显式假设见 `data/assumptions.md`，其中影响最大的几条：

1. 预测区间取 2023/12/1–12/30（题面只写"未来 30 天"）；
2. 附件 3 视为过去 90 天的日均线路货量且进出平衡（合计 18,977）；
3. 线路关闭后货量在网内重分配，全网总量守恒；
4. 小时占比在 30 天内稳定，缺失小时视为零货量（不插值）；
5. 人效取题面上限；无成本系数，故目标为"人天数最小 + 人效均衡"；
6. 排班允许班次内积压，但当日 24 点前必须清零（Hall 条件）；
7. 问题 4 沿用问题 3 的班次人力需求（逐格总人数不变），只做"正式工优先 + 临时工补足"的逐人落地。
